# Sit With It
**Медленные философские вопросы. Без правильных ответов.**
Веб-приложение для рефлексии, самоанализа и философских размышлений. Более 1000 вопросов в 35 категориях, система прогресса, достижений и ежедневных цитат.

## Особенности
- **1050 философских вопросов** в 35 категориях
- **Система уровней** — от Начинающего до Легенды
- **Достижения** — более 80 достижений, включая редкие
- **Ежедневная цитата** философа
- **Вопрос дня** — новый вопрос каждый день
- **Прогресс-бары** — отслеживание ответов по категориям
- **Закладки** — сохраняйте любимые вопросы
- **Свои вопросы** — добавляйте до 100 собственных вопросов
- **Голосовой ввод** — диктуйте ответы
- **Экспорт** — TXT, JSON, PDF, CSV, Markdown
- **Резервное копирование** — полный экспорт и импорт данных
- **Авто-ночная тема** — с 22:00 до 6:00 по вашему часовому поясу
- **Офлайн режим** — работает без интернета
- **Адаптивный дизайн** — телефон, планшет, компьютер
- **Service Worker** — PWA-поддержка

## Достижения

Достижения делятся на **обычные** и **редкие** (выделены синим цветом).

### По количеству ответов
- Первый шаг, Любопытный, Мыслитель, Пытливый ум, Исследователь, Мастер, Эрудит, Философ, Мудрец, Просветлённый, Гений, Грандмастер, Оракул, Бесконечный, Абсолют

### По серии (streak)
- 3, 7, 14, 30, 60, 150, 200, 500, 1000 дней подряд

### По созданию своих вопросов
- 1, 3, 5, 20, 50, 100 вопросов

### По категориям
- Знаток каждой из 35 категорий + Перфекционист + Мастер всего

### По закладкам
- 10, 25, 50, 100 закладок

### По экспорту
- 1, 5, 10, 25 экспортов

### Временные
- Ночная сова (10 раз после полуночи)
- Сова (25 раз после полуночи)
- Жаворонок (10 раз до 6:00)
- Ранняя пташка (25 раз до 6:00)

### По длине ответов
- Краткость — сестра таланта (1 слово)
- Многословный (500+ символов)
- Писатель II (3000+ символов)
- Роман (5000+ символов)
- Эссеист (10 ответов на 1000+ символов)

### По категориям-путешественник
- Путешественник (10 категорий)
- Исследователь II (20 категорий)
- Исследователь III (все категории)

### По использованию сайта
- 1, 7, 30, 100, 365 дней

### По рандомным вопросам
- 1, 10, 50 открытий

### Другие
- Редактор (5 изменений своих вопросов)
- Перфекционист II (3 очистки и перезаписи ответа)
- Ежедневный, Ежедневный II, Ежедневный III, Мастер ежедневных вопросов

## Горячие клавиши
| Сочетание | Действие |
|-----------|----------|
| `Ctrl + Enter` | Сохранить ответ |
| `Ctrl + F` | Открыть поиск |
| `Esc` | Закрыть модальное окно |
| `←` / `→` | Навигация между вопросами |

## Установка и запуск
1. Скачайте все файлы проекта
2. Откройте `index.html` в браузере
Для PWA-режима (установка как приложение):
- Используйте браузер с поддержкой PWA (Chrome, Edge, Brave)
- Откройте сайт → нажмите «Установить» в адресной строке

## Технологии
