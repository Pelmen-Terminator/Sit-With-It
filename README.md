# Sit With It
**Медленные философские вопросы. Без правильных ответов.**
Веб-приложение для рефлексии, самоанализа и философских размышлений. 1200 вопросов в 40 философских категориях, система прогресса, достижений и ежедневных цитат.


## Обновление 2.0.5
- Категории организованы в шесть тематических разделов.
- «Мои вопросы» закреплены в самом низу списка категорий.
- Добавлены 6 категорий по 30 вопросов каждая: всего 40 категорий и 1200 встроенных вопросов.
- Достижение «Бесконечный» теперь открывается после 1000 ответов. Ранее полученное достижение сбрасывается, если новый порог ещё не достигнут.
- Для каждой из 40 категорий предусмотрено отдельное достижение «Знаток».
- Сохранены идентификаторы прежних достижений категорий, чтобы не сбрасывать уже полученный прогресс там, где это возможно.
- Обновлён кэш Service Worker.

## Особенности
- **1200 философских вопросов** в 40 категориях
- **Система уровней** — от Начинающего до Легенды
- **Достижения** — 106 достижений, включая редкие
- **Ежедневная цитата** — расширенная подборка философских цитат и авторских размышлений
- **Вопрос дня** — новый вопрос каждый день
- **Ежедневные уведомления** — настраиваемое время напоминания, защита от повторов в течение дня и переход к вопросу по нажатию
- **Прогресс-бары** — отслеживание ответов по категориям
- **Закладки** — сохраняйте любимые вопросы
- **Случайный вопрос** — избегает повторения последних пяти случайных вопросов
- **Свои вопросы** — добавляйте до 100 собственных вопросов
- **Голосовой ввод** — непрерывная диктовка с добавлением к существующему тексту и понятными сообщениями об ошибках
- **Экспорт** — TXT, JSON, PDF, CSV, Markdown
- **Резервное копирование** — полный экспорт и импорт данных
- **Авто-ночная тема** — с 22:00 до 6:00 по выбранному часовому поясу; региональные зоны учитывают сезонный перевод часов
- **Автоматический часовой пояс** — определение зоны устройства или выбор региона вручную
- **Адаптивный размер** — автоматическая подстройка под ширину экрана и ориентацию устройства
- **Индивидуальные карточки категорий** — цветные иконки и отображение прогресса
- **Офлайн режим** — работает без интернета
- **Адаптивный дизайн** — телефон, планшет, компьютер
- **Живые анимации** — пружинная отдача нажатий, плавные переходы между экранами, шторки с жестом «смахнуть вниз», конфетти за достижения, круговая смена темы
- **Уважение к `prefers-reduced-motion`** — при отключённой анимации в системе все эффекты выключаются
- **Service Worker** — PWA-поддержка

## Достижения

Достижения делятся на **обычные** и **редкие** (выделены синим цветом).

### По количеству ответов
- Первый шаг, Любопытный, Мыслитель, Пытливый ум, Исследователь, Мастер, Эрудит, Философ, Мудрец, Просветлённый, Гений, Грандмастер, Оракул, Бесконечный, Абсолют

### По серии (streak)
- 3, 7, 14, 30, 60, 150, 200, 500, 1000 дней подряд

### По созданию своих вопросов
- 1, 3, 5, 20, 50, 100 вопросов

### По категориям
- Знаток каждой из 40 категорий + Перфекционист + Мастер всего

### По закладкам
- 10, 25, 50, 100 закладок

### По экспорту
- 1, 5, 10, 25 экспортов

### Временные
- Ночная сова (10 раз после полуночи)
- Сова (25 раз после полуночи)
- Жаворонок (10 раз до 6:00)
- Ранняя пташка (25 раз до 6:00)

### По длине ответов
- Краткость — сестра таланта (1 слово)

- Писатель II (3000+ символов)

- Исследователь II (20 категорий)
- Исследователь III (все 34 категории)

### По использованию сайта
- 1, 7, 30, 100, 365 дней

### По рандомным вопросам
- 1, 10, 50 открытий

### Другие
- Редактор (5 изменений своих вопросов)

- Ежедневный, Ежедневный II, Ежедневный III, Мастер ежедневных вопросов

## Установка и запуск
1. Скачайте все файлы проекта
2. Откройте `index.html` в браузере
Для PWA-режима (установка как приложение):
- Используйте браузер с поддержкой PWA (Chrome, Edge, Brave)
- Откройте сайт → нажмите «Установить» в адресной строке

## Технологии
- HTML / CSS (Native, без фреймворков)
- JavaScript (Vanilla)
- localStorage для хранения данных
- Service Worker (PWA)
- Web Speech API (голосовой ввод)
